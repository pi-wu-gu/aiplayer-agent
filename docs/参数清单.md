## 8770 控制台（运行中热改，无需重启 daemon）
浏览器开 `http://127.0.0.1:8770/`：左列运行参数（保存即热生效，写入 daemon_state.json 重启恢复）、
中列实时行为流（思考/工具调用，思考行点击展开全文与推理链，折叠状态跨刷新保持）、右列状态与积压。

**可热改参数共 13 项**（`GET/POST /config` 同效）：
- 运行参数（10）：poll_interval / wake_interval / wake_check_backlog / review_every /
  review_llm / **review_token_budget** / max_rounds_per_run / run_cooldown / backlog_max / say_on_start
- token 熔断（1）：**session_token_budget**（写 cost_guard 段，Reviewer R4 每轮实时读 → 改完即生效；0=关闭）
- 列表（2）：bot_names / mention_extra

密钥（keys.yaml）不在热改列。2026-10-17 起任务收尾不再发游戏消息（统计只进日志/控制台）。

## sidecar 部署（已实现，随模组分发）
- 模组 jar 内嵌 `assets/aiplayer/agent_bundle.zip`（源码 + python-embed 运行时 + wheels），
  首次启动解压到 `<游戏目录>/aiplayer-agent/<模组版本>/`；按版本目录缓存，**bundle 变了必须升 mod_version**
- 升级时保留 keys.yaml / config/config.yaml / logs（`inheritFromPrevious` / `preserveAndClear`）
- 模组侧 ensure_running：8770 已有 daemon 实例则复用，否则 `python run.py --daemon` 拉起，
  另有 watchdog 保活 → **部署换包必须先确认旧 daemon 已退出**，否则新客户端会复用跑旧代码的 daemon
- 打包：`python scripts/build_agent_bundle.py`（含内嵌运行时烟测；keys/日志/审计绝不入包）

**合计 64 项**（defaults 4 + llm 4 + cost_guard 4 + orchestrator 3 + tool_maker 3 + context 2 +
mc_bridge 4 + permissions 19 + daemon 18 + logging 3），另有 keys.yaml 的 providers 结构与模组侧 5 轴。
