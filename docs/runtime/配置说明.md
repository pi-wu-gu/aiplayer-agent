# 配置说明（三层配置地图）

> 目的：回答"我想改 X，该动哪个文件、多久生效"。2026-10-17 整理（v0.2.1.21）。
> 模组层每个键的详细中文说明已内置游戏内配置界面（悬停即见），本文不重复。

## 0. 速查：想做什么 → 改哪里

| 想做什么 | 改哪里 | 生效 |
|---|---|---|
| 换模型 / 调温度 | `PCL2/agent/config/config.yaml` → `defaults` | 重启 daemon |
| 调 token 上限（熔断/提前审查） | 8770 控制台左列输入框，或 `POST 8770/config` | ⚡即时热生效 |
| 换目标服务器 / 关自动登录 | 模组 `serverAddress`（留空=不自动登录） | ⚡即时 |
| 断线自动重连开关 / 次数 | 模组 `autoReconnect` / `reconnectDelaySec` / `autoConnectMaxAttempts` | ⚡即时 |
| 让 agent 只读不动（纯观察） | 模组 `permissions.gameActionMode = "observe"` | ⚡即时热切换 |
| 禁 agent 读写文件 | 模组 `permissions.fileMode = "readonly"/"off"` | ⚡即时热切换 |
| 禁 /命令 动作 | 模组 `permissions.commandEnabled = false` | ⚡即时热切换 |
| 改成本护栏 / 唤醒策略 | agent `config.yaml` → `cost_guard` / `daemon` | 重启 daemon |
| 看/改 agent 运行参数 | 浏览器 `http://127.0.0.1:8770/`（左列保存即热生效）；`curl 8770/config` 只读 | ⚡即时 |
| 换 bot 用户名 / 内存 / Java | 启动器 `PCL2/AI/config/ai_player.json` | 下次启动 |
| 换运行数据目录 | 模组 `dataDirectory` | ↻重启，**且不迁移旧数据** |
| 改控制服务端口/地址 | 模组 `controlHost` / `controlPort` | ↻重启 |
| 关掉整个 AI 模块保平安 | 模组 `enabled = false` | ↻重启 |

## 1. 三层配置总览

| 层 | 文件 | 管什么 | 管理方式 |
|---|---|---|---|
| 启动器 | `PCL2/AI/config/ai_player.json` | 实例参数：用户名/内存/Java/各目录路径；`auto_join` 已于 2026-10-17 **停用**（从未生效过：quickPlay 链路无 quickPlayPath.json） | 手改 |
| 模组 | `PCL2/AI/game/config/aiplayer-common.toml`（37 键） | 总开关/自动登录/内嵌控制服务(8780)/权限表/sidecar/内置 AI API | 游戏内「模组→AI Player→配置」直接改（每项悬停有中文 tooltip） |
| agent（sidecar） | `PCL2/agent/config/config.yaml`（+ `roles.yaml` + `keys.yaml`） | 模型与采样/成本护栏/daemon 唤醒策略/权限镜像/`shell` 高危开关/`web` 抓取开关 | 手改 yaml；运行参数可 `GET 8770/config` 查看、`POST 8770/config` 热改白名单参数 |

**为什么是三层**：模组是"丢进任意整合包就能用"的可分发组件，只承载游戏内能力；
agent 是跑在旁边的 Python 决策进程（可以离游戏存活）；启动器只负责把客户端拉起来。
三者各有各的配置文件，互不强耦合。

## 2. 模组层 37 键分组

- **总开关与数据**（7）：`enabled`（↻重启）、`brainEnabled`（⚠死键）、`dataDirectory`（↻重启+不迁移）、
  `verbose`（⚡）、`pollIntervalMs`（⚠死键）、`logKeepDays`（⚠死键）、`shutdownMessage`（⚡，≤100字）
- **自动登录**（5）：`serverAddress` / `autoLogin` / `autoReconnect` / `reconnectDelaySec` /
  `autoConnectMaxAttempts`（全 ⚡）。
  ★唯一入口就在模组层；启动器层已停用
  ★`autoConnectMaxAttempts`（默认 2，范围 1-20）= 自动连接最大尝试次数：同一进程内累计，
  成功进世界后重置；用尽后若停在断开界面→**自动回主界面并不再自动连接**，重启客户端重新计数
- **内嵌控制服务 8780**（5）：`controlEnabled`（↻）、`controlHost`（↻，保持 127.0.0.1）、
  `controlPort`（↻）、`controlToken`（⚡，每请求校验）、`networkEnabled`（⚡，内置 AI 出站总闸）
- **内置 AI API**（10）：`apiProvider`/`apiBaseUrl`/`apiKeyEnv`/`apiKey`/`model`/`apiHeadersJson`/
  `apiExtraBodyJson`/`apiTimeoutMs`/`apiTemperature`/`apiMaxTokens`（全 ⚡，每次调用读取）。
  ★当前内置大脑未启用（`brainEnabled` 死键），这套配置实际待用状态
- **权限表**（4，全 ⚡即时热切换）：`fileMode` / `commandEnabled` / `selfToolEnabled` / `gameActionMode`
- **sidecar**（6，全 ↻重启）：`enabled` / `deployDir` / `autoStart` / `launchMode` / `pythonPath` /
  `watchdogInterval`。★双客户端只在 AI 端开

## 3. 热加载边界（为什么有的即时有的要重启）

NeoForge 框架行为：toml 变化即重载配置值，**没有自建 watcher**。
- **⚡即时生效** = 代码每次读取都取新值（权限表/自动登录/API 系列/controlToken/verbose…）
- **↻需重启** = 启动时一次性绑定：`enabled`/`controlEnabled` 在客户端初始化时读；
  `controlHost`/`controlPort` 在控制服务构造时绑定；`dataDirectory` 在路径模块初始化时定；
  sidecar 六项在 agent 拉起流程里读
- **⚠死键** = 定义了但源码零调用方：`brainEnabled` / `pollIntervalMs` / `logKeepDays
  （v0.1 时代遗留，内置大脑轮询与日志清理从未接线，实际由 sidecar agent 承担）
- **agent 侧**：`config.yaml` 改了要重启 daemon；`POST 8770/config` 或 8770 控制台可在运行中热改
  13 项白名单参数（唤醒词/轮询间隔/审查策略/两个 token 上限等，keys.yaml 的密钥不在其列）
- **任务收尾不再发游戏消息**（2026-10-17 用户要求）：session_stats 只进日志/控制台；
  仅保留启动/下线播报与重启前 say（服务器礼仪）

## 4. 两级权限闸门（别混）

| | 模组侧 `[permissions]` | agent 侧 `config.yaml → permissions` |
|---|---|---|
| 管什么 | 动作要不要进注册表（装配期） | 文件工具白名单 + shell 高危开关 + web 抓取开关 |
| 档位 | fileMode(full/readonly/off)、commandEnabled、selfToolEnabled、gameActionMode(full/safe/observe) | file_mode(full/readonly/off)、roots(白名单根)、shell(enabled/allowlist/…)、web(enabled/allow_from_chat/…) |
| 生效 | ⚡装配期快照比对，热切换 | off 时工具不注册；readonly 只注册只读工具 |
| 关系 | **两道独立的闸**：模组先把动作摘掉，agent 侧再收窄自己的工具面 | `roles.yaml` 的 file_mode 只能更严（intersect），不会放宽 |

改模组侧 `gameActionMode=safe` 时 agent 侧无感知——这是设计（两级闸），不是 bug。

## 5. 密钥在哪（唯一真实密钥）

- **唯一在用的密钥**：`PCL2/agent/config/keys.yaml`（sidecar agent 调 DeepSeek 用，绝不外泄/不进 jar）
- 模组侧 `apiKey` **已于 2026-10-17 清空**：内置大脑没开，那是死配置。
  将来要用内置大脑 → 设环境变量 `AI_PLAYER_API_KEY`（`apiKeyEnv` 指向它），别往 toml 写明文
- 日志脱敏：agent 侧 `logging.redact_keys=true`；模组侧日志永不回显密钥值
- 启动器 `ai_player.json` 无密钥
